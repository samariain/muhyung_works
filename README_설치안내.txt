===============================================================
 무형상품팀 Co-Works 대시보드 — 설치 / 이전 안내 (1단계 버전)
===============================================================

이 폴더는 팀 공용 대시보드를 "새 노트북(서버 PC)"에서 바로 띄우기 위한
파일 묶음입니다. 파이썬 표준 라이브러리만 사용하므로 추가 설치가 거의
없습니다.

---------------------------------------------------------------
[ 폴더에 들어있는 파일 ]
---------------------------------------------------------------
 - dashboard.html   : 대시보드 화면 (팀 전원이 브라우저로 보는 페이지)
 - server.py        : 로컬 공유 서버 (데이터 저장 + 팀 공유)
 - 서버켜기.bat      : 서버 실행 파일 (더블클릭) — 자동 재시작 포함
 - README_설치안내.txt : 이 문서

 ※ data.json 과 backups/ 폴더는 "서버를 처음 켜면 자동으로 생성"됩니다.
   (기존 노트북의 데이터를 가져오려면 아래 [기존 데이터 이전] 참고)

---------------------------------------------------------------
[ 사전 준비 : 파이썬 설치 (최초 1회) ]
---------------------------------------------------------------
 새 노트북에 파이썬이 없으면 설치하세요.
 1) https://www.python.org/downloads/ 에서 Windows용 설치
 2) 설치 첫 화면에서 "Add Python to PATH" 체크 필수
 3) 설치 후, 명령창(cmd)에서  python --version  이 나오면 완료

---------------------------------------------------------------
[ 설치 / 실행 ]
---------------------------------------------------------------
 1) 이 폴더(압축 푼 전체)를 새 노트북의 원하는 위치에 둡니다.
    예:  바탕화면\kpi-dashboard\
 2) 폴더 안의  서버켜기.bat  을 더블클릭합니다.
 3) 검은 창에 주소가 표시됩니다.
      - 이 PC에서 보기 :  http://localhost:8000
      - 팀원(같은 네트워크):  http://<이 PC의 IP>:8000
 4) 브라우저에서 위 주소로 접속 → 조회 비밀번호 입력

 ※ 검은 서버 창은 켜 둔 상태로 두어야 팀원이 접속할 수 있습니다.
   (창을 닫으면 서버가 꺼집니다. 자동 재시작은 '창이 열려 있는 동안'만
    동작합니다.)

---------------------------------------------------------------
[ 비밀번호 ]
---------------------------------------------------------------
 - 조회(팀 공용)  : 2026
 - 관리자(입력)   : 0000
   * 관리자 비번은 "일일실적 / 월 목표 / 영업일" 입력에만 필요합니다.
   * 공지 / 소담 / 방송편성 / 팀스케줄 / 워크플로우는 누구나 입력 가능.

 [ 비밀번호 변경 방법 ]
   - 조회·관리자 비번(화면쪽) : dashboard.html 상단의
        var VIEW_PW='2026';   var ADMIN_PW='0000';
   - 관리자 비번(서버쪽)      : server.py 의
        ADMIN_PW = "0000"
   * 관리자 비번은 dashboard.html 과 server.py 두 곳을 "같은 값"으로
     맞춰야 합니다. 변경 후 서버를 껐다 켜세요.

---------------------------------------------------------------
[ 팀원 접속용 IP 확인 ]
---------------------------------------------------------------
 1) 서버 PC에서 명령창(cmd) 실행 →  ipconfig  입력
 2) "IPv4 주소" (예: 192.168.0.25) 를 팀원에게 공유
 3) 팀원은 브라우저에  http://192.168.0.25:8000  입력
 ※ 방화벽에서 처음 한 번 "액세스 허용"을 물으면 허용하세요.
 ※ 같은 사내 네트워크(와이파이/랜)에 있어야 접속됩니다.

---------------------------------------------------------------
[ 데이터 저장 / 백업 (자동) ]
---------------------------------------------------------------
 - 모든 입력은  data.json  에 저장되며 팀 전원이 같은 데이터를 봅니다.
 - 저장할 때마다  backups\  폴더에 직전 상태가 자동 백업됩니다(최근 30개).
 - data.json 이 손상돼도 자동으로 최신 백업에서 복구를 시도합니다.
 - 중요: data.json 과 backups\ 폴더는 지우지 마세요. (팀 운영 데이터)

---------------------------------------------------------------
[ 기존 노트북의 데이터 이전 (선택) ]
---------------------------------------------------------------
 지금까지 입력한 실적·공지·일정 등을 새 노트북으로 그대로 옮기려면:
 1) 기존 노트북 서버 폴더에서  data.json  (있으면 backups\ 폴더도) 복사
 2) 새 노트북의 이 폴더(dashboard.html 이 있는 곳)에 붙여넣기
 3) 서버켜기.bat 실행
 ※ 새로 시작(빈 상태)할 거라면 이 단계는 건너뛰면 됩니다.
   (서버를 켜면 빈 data.json 이 자동 생성됩니다)

---------------------------------------------------------------
[ 월별 대시보드 안내 ]
---------------------------------------------------------------
 - 화면 상단의 월 선택기로 달을 바꿀 수 있습니다(과거/다음 달 포함).
 - 기본은 "현재 월"이 표시되고, 다음 달을 미리 선택해
   목표·방송편성·팀스케줄을 사전 셋업할 수 있습니다.
 - 월이 바뀌면 그 달 기준으로 전환되며, 과거 달 데이터는 보존됩니다.

---------------------------------------------------------------
[ 자주 겪는 문제 ]
---------------------------------------------------------------
 - "python 명령을 찾을 수 없음" → 파이썬 미설치/PATH 미체크. 재설치.
 - "포트 8000 사용 중" → 이미 서버가 떠 있습니다. 기존 검은 창을 닫고
   다시 실행하세요.
 - 팀원이 접속 안 됨 → 같은 네트워크인지, IP가 맞는지, 방화벽 허용했는지
   확인. 서버 PC가 켜져 있고 검은 창이 열려 있어야 합니다.
 - 저장이 안 되고 "서버에 연결 실패" → 검은 서버 창이 꺼져 있는지 확인.
